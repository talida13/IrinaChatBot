# IrinaChatBot

This project is an **Ionic React application** integrated with **Botpress Webchat**.  
It is built for the course **Dialog Systems and Virtual Assistants** and aims to help **international students in Iași** with administrative procedures, university information, and student life guidance.

---

## Tech Stack

- **Ionic React**
- **React**
- **Vite**
- **Botpress Webchat**

---

## Project Purpose

The chatbot helps international students with topics such as:

- admission and required documents
- residence permit information
- accommodation and dormitories
- university services
- courses and campus life
- student life in Iași

---

## Prerequisites

Before running the project, make sure you have installed:

- **Node.js** (recommended: latest LTS version)
- **npm**
- **Ionic CLI**

You can check if they are installed with:

```bash
node -v
npm -v
ionic -v
```
